# CASIO fx-50FH II 網頁版計數機

這是一個仿照香港考評局認可計數機 **CASIO fx-50FH II** 製作的網頁版計數機，適合在課堂上用電腦、投影機或平板示範按鍵次序。

- 整個程式只有一個檔案：`index.html`。字型、程式碼和顯示屏點陣字全部已內嵌，**不用上網**，用 Chrome、Edge 等瀏覽器雙擊打開即可。
- 機身、按鍵和 LCD 全部用 HTML、CSS 和 SVG 繪畫，沒有使用相片，放大投影都清晰。
- 計數機的狀態（記憶、變數、設定）和介面偏好（模式、按鍵聲、記錄位置、播放速度）會自動儲存在瀏覽器，下次打開時保留。

## 兩個模式

畫面頂部的切換掣可以選擇模式：

| 模式 | 用途 |
|---|---|
| **計數機模式** | 只顯示計數機，操作方式與真機相同。 |
| **教師示範模式** | 計數機下方（或右側）會多出「教師按鍵記錄」，記下老師按過的每一粒鍵，方便學生跟着做。 |

## 教師示範模式用法

1. 按頂部的「教師示範模式」。
2. 直接按畫面上的計數機（滑鼠、觸控或電腦鍵盤都可以）。每按一粒鍵，記錄區就會加入一個與真機按鍵外觀相近的「按鍵方塊」，左上角有步驟編號。
   - **SHIFT／ALPHA 組合**：例如 SHIFT sin 會記錄成「SHIFT」方塊，再加一個上方寫着橙色「sin⁻¹」的 sin 方塊。ALPHA 功能則用紅色字標示。
   - **選單內按數字**：例如 MODE 之後按 1，方塊上方會註明「COMP」。
3. 每按一次 **EXE**，記錄會自動分成新一行「算式 n」，並在後面顯示答案（例如「= 7.」）。按 **AC** 會開始新一行。M+、M−、STO、選單選擇或出現錯誤時，也會結束該行。
4. 記錄區的按鈕：
   - **▶ 播放示範**：把計數機還原到開始記錄時的狀態，然後逐步重播每一粒鍵。被按的鍵會以黃色框高亮，對應的方塊亦會同步高亮，顯示屏亦會逐步變化。播放途中再按一次（■ 停止）可以中止。
   - **每步 … 秒**：調校播放速度，範圍是每步 0.2 至 2.5 秒。
   - **復原上一步**：刪除最後一粒鍵，計數機亦會回到按該鍵之前的狀態。
   - **清除記錄**：清空所有記錄。
   - **複製文字**：把按鍵次序複製成純文字，可貼到工作紙或簡報，例如：
     `算式 2：[SHIFT] [sin⁻¹] [0] [•] [5] [EXE]  ⇒ = 30.`
   - **記錄位置：下方／右側**：切換記錄區在計數機下方或右側。預設是下方；在 16:9 投影機上改為「右側」，計數機會顯示得較大。

記錄區的字和方塊特意做得較大，方便投影時學生在課室後排也看得清楚。

## 已實現的功能

**輸入與編輯**
- 與真機相同的自然輸入次序：先輸入算式，再按 EXE。
- 答案存入 Ans。算出答案後直接按運算符號（例如 ×），會自動以 Ans 開頭。
- 頂行是 16 字點陣顯示（5×7 點）：
  - 長算式會左右捲動，並顯示 ◀ ▶ 提示。
  - 游標會閃動：插入模式是直線，覆寫模式（SHIFT DEL = INS）是底線。
- DEL、INS、AC、ON；SHIFT AC（OFF）會關機，按 ON 再開機。
- REPLAY 方向鍵：◀ ▶ 移動游標修改算式；▲ ▼ 翻查之前的算式。
- 出現錯誤後按 ◀ 或 ▶，游標會跳到出錯的位置。

**運算**
- 運算優先次序跟從 fx-50FH 說明書，包括括號、隱藏乘號（例如 2π、3(4+5)），以及負號 (−) 與減號的分別。
- 算式末尾未閉合的括號會自動補上。
- 程式用自寫的分析器（tokenizer 加遞迴下降 parser）計算，沒有使用 `eval`。

**函數**
- sin、cos、tan 及其反函數；hyp（sinh、cosh、tanh 及其反函數）。
- log、ln、10ˣ、eˣ、log(a,b)。
- √、∛、x²、x³、x⁻¹、^、ˣ√、x!、nPr、nCr、Abs、%。
- π、e、Ran#、Rnd。

**角度**
- SETUP 可設定 Deg、Rad 或 Gra，顯示屏上有 D、R 或 G 指示。
- DRG▸ 可為輸入值加上 °、ʳ 或 ᵍ 單位作換算。

**分數**
- 用 a b/c 輸入分數，例如 1┘2 + 1┘3 = 5┘6。
- 按 a b/c 在分數與小數之間切換；按 SHIFT d/c 在帶分數與假分數之間切換。
- SETUP 可設定預設用 ab/c 或 d/c。

**度分秒**
- 用 °′″ 鍵輸入，例如 2°15°30°。
- 按 °′″ 鍵在度分秒與小數之間切換；SHIFT ← 會轉回小數。

**數值格式**
- ENG 及 SHIFT ←（ENG←）按工程記數法調整指數。
- EXP 輸入 ×10ⁿ，例如 2 EXP 3 = 2000。
- SETUP 提供 Fix（0–9 位小數）、Sci（1–10 位有效數字）和 Norm 1／2，顯示屏有 FIX、SCI 指示。
- 主顯示行是 10 位 7-segment 數字，未亮的筆劃會淡淡顯示。另有負號、小數點，以及 ×10 加兩位指數。

**記憶與變數**
- M+、M−（SHIFT M+）、RCL M，有 M 指示。
- STO 可存入變數 A、B、C、D、X、Y、M；ALPHA 加變數鍵可叫出變數。
- SHIFT 9（CLR）可選擇清除 Mem、Setup 或 All。

**座標轉換**
- Pol(x,y) 和 Rec(r,θ)，結果同時存入 X 和 Y。

**模式選單**
- **COMP**：一般計算。
- **SD**：單變數統計。用 M+（DT）輸入數據，可輸入次數，可用 ▲▼ 查看及修改數據；S-SUM 和 S-VAR 提供 x̄、σx、sx 等結果。
- **REG**：雙變數迴歸，提供 Lin、Log、Exp、Pwr、Inv、Quad、AB-Exp 七種，可求 A、B、C、r、x̂、ŷ。

**其他設定與功能**
- **CONST**：40 個科學常數。
- **FMLA**：23 條內置公式，例如 17:Doppler，會逐個提示輸入變數再顯示結果。
- **錯誤訊息**：Math ERROR、Syntax ERROR、Stack ERROR、Data Full（Arg ERROR 只在未提供的模式出現，所以沒有）。
- **SETUP 其他設定**：統計次數 FreqOn／FreqOff、顯示屏對比度。

**介面**
- 每粒鍵都有 3D 按下效果（按下時下沉並改變陰影），亦有滑鼠懸停回饋。
- SHIFT／ALPHA 啟動後，按鍵會有外框提示，顯示屏亦會亮起 S 或 A。
- 按鍵聲用 Web Audio 即時合成，沒有使用外部音效檔，頂部可以開關。
- 支援滑鼠和觸控（平板）。畫面會按視窗大小自動縮放，適合 16:9 電腦或投影機，以及平板直放或橫放。

## 與真機的分別及限制

- **未有提供**：
  - CMPLX（複數）、BASE（進制）和 PRGM（程式）模式。選擇後會顯示「Not supported」，並有中文提示。
  - Prog 鍵（執行程式）也未有提供；SHIFT Prog（EXIT）只會返回。
  - 只在上述模式使用的鍵沒有作用：P-CMD、Re⇔Im、∠、i、arg、Conjg、▸r∠θ、▸a+bi，以及 DEC、HEX、BIN、OCT、LOGIC。
- **變數**：真機只有 A、B、C、D、X、Y、M 七個變數，網頁版亦一樣。cos、tan 上方的 E、F 是 BASE 模式的十六進制數字，不是變數。
- **科學常數**：數值按說明書所列的 CODATA 2000。
- **FMLA**：公式名稱和變數標籤是按說明書整理的，顯示字樣可能與真機有少許不同。
- **計算精度**：網頁版用電腦的雙精度浮點數，內部約 15 至 16 位有效數字，再按真機規則顯示 10 位。極端情況下，最後一位的進位可能與真機有分別。
- **輸入長度**：網頁版沒有限制 99 bytes，所以不會出現真機輸入過長時的提示。
- **顯示屏**：
  - 點陣字型和 7-segment 筆劃是仿造的，外觀與真機相近，但不是逐點一樣。
  - 錯誤訊息的位置、選單數字的排位亦是按說明書推斷。
- **其他**：沒有自動關機功能，沒有太陽能或電池模擬。
